### Kykloi - Task List Support

Kykloi supports task lists via Pandoc in the Github manner.

#### Markdown Syntax

```markdown
- [x] Completed task
- [ ] Incompleted task
```

Task lists can be nested with indents.

```markdown
- [ ] Task
  - [ ] Sub task one
  - [ ] Sub task two
```
